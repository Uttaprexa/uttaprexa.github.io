GRPO, built from scratch

The reinforcement-learning method behind DeepSeek-R1, written without any training library. This is one training step on one math problem, then what happens when every answer is wrong.

8.7 → 28.5%GSM8K accuracy, Qwen2.5-0.5B, 300 GRPO steps

1.7×faster answer checking after moving it to C++
25tests that run without a GPU

How it's built

Async rollout workers (Trio) generate answers in parallel; if any worker fails, the whole step stops instead of training on a half-filled batch. Rewards come from a checker that reads the final number in four answer formats, so there's no reward model to fool. Model-written code for coding tasks runs in a separate process with memory and time limits. The comparison ran PPO, GRPO and DPO with the same model, data, hardware and settings on an AWS T4 GPU.

Python · PyTorch · Hugging Face Transformers · Trio · C++/pybind11 · FSDP support · Kubernetes manifests · AWS EC2

Reading the comparison honestly

One seed, 200 test problems. DPO and GRPO are within two problems of each other, so they're effectively tied; both clearly beat the starting model. Multiple seeds and denser, step-level rewards are the next experiments.
