Memory that keeps up with you

Long conversations push early facts out of a chatbot's view. This agent decides on every turn whether to remember, update or ignore what you said, so it still knows you're vegan 90 turns later.

0.760answer accuracy, vs 0.613 for a retrieval baseline
−64%missed facts compared with keyword rules
75test conversations, 60–100 turns each
0.86+accuracy at every distance between fact and question

How it's built

For each user message, a Claude call returns one of three decisions and, when storing, a key and value. Memory is a small set of named slots; a newer value for the same key replaces the old one. Answers are written from the slots plus the last few turns. I compared it with four alternatives: keeping only recent turns, a short rolling summary, similarity search over past turns, and keyword rules.

Python · Claude API · sentence-transformers (all-MiniLM-L6-v2) · Gradio demo

Test set

75 generated conversations across 15 topics, with preferences that change more than once, reworded statements, and facts about other people that must not be stored as yours. Every conversation has known correct answers.
